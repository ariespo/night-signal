# 夜间电台 · Night Signal 1.10

SillyTavern 1.19.0 起可用的 Mixtape 界面扩展。标题菜单接入继续聊天、最近聊天、角色管理和设置。

## 安装

### 从 GitHub 安装扩展

1. 在 SillyTavern 的顶部打开「扩展程序」，点击「安装扩展程序」。
2. 粘贴 `https://github.com/ariespo/night-signal.git`，保持分支为空，点击「安装」或「只给我安装」。
3. 输入框旁的魔杖菜单里选择「夜间电台」。后续可在「管理扩展程序」里检查和安装更新。

GitHub 提供安装和更新。装好以后，页面、字体、图像和声音都由你正在使用的 SillyTavern 服务提供。

### 其他安装方式

**手动安装**。从 [GitHub Releases](https://github.com/ariespo/night-signal/releases) 下载并解压 `night-signal-1.10.2.zip`，将其中的 `night-signal` 文件夹放入 SillyTavern 的 `data/<用户名>/extensions/`。默认位置为 `data/default-user/extensions/night-signal/`。更新时覆盖同名文件并刷新酒馆。若曾手动安装且想改用 GitHub 更新，可先备份现有扩展目录并将它移到 `extensions/` 之外，再用上面的链接安装。

**酒馆助手版**。从 [GitHub Releases](https://github.com/ariespo/night-signal/releases) 下载「酒馆助手全局脚本（JSON）」，在「酒馆助手 → 脚本 → 全局脚本 → 导入」选择下载的文件，然后开启「夜间电台」。原生扩展和全局脚本任选一种。

**UI 主题预设**。在「用户设置 → UI 主题」导入 `Mixtape-夜间电台-主题.json` 可以应用聊天颜色与基础外观。标题菜单、转场、旋转与音频由扩展版或酒馆助手版加载。

## 操作

- 标题页默认使用烟茶色透明 MD，可在「扩展程序 → 夜间电台 → 标题主题」切换深蓝 MD 录音机。两款机身都带 `poaries` 作者铭刻。方向键切换焦点，Enter 确认，Esc 返回。
- 打开聊天后会进入歌词内页。大屏按左页、右页的顺序读，手机按单页读。底部可输入页码跳转，也可一次向前或向后跳 10 个阅读页。「跳到楼层」按酒馆的消息编号定位。分页随字号和屏幕尺寸调整。页数后的 `+` 表示还有更早的聊天，继续往前翻可加载。
- 正文段落首行缩进两个汉字。指针和触摸会移动纸面上的柔和漫反射，纸纤维、装订折痕和文字仍然清晰。减弱动效模式保持固定光照。
- 「阅读设置」可选择正文字体，调整字号、纸面颜色，以及正文、斜体、引号和下划线颜色。乐米栀夏浅风体从本机安装的字体读取。编辑消息和切换回复使用楼层原有的控件。「原生视图」可恢复酒馆聊天布局，魔杖菜单中的「打开歌词内页」可切回。
- 标题上的「设置」打开「预设设置」。阅读器顶部的「世界书」「角色管理」和「扩展程序」可以直接打开对应的唱片盒细页。使用左右箭头切换枚举和开关，拖动带数字的进度条调整范围参数。
- 「扩展程序 → 夜间电台 → 启用夜间电台」可以关闭或重新启用主题，开关状态会保存。「界面显示」可单独隐藏思维链、消息操作、名字、头像、日期与时间和输入栏工具。酒馆的顶部导航默认隐藏，可在这里恢复。
- 世界书可直接调激活参数和匹配规则，也可进入书库、条目列表、正文编辑和筛选。只滚动唱片盒中央的列表，标题、Hot Stuff 贴纸和底部两张标签固定在盒面。关键词和正文编辑由酒馆保存。
- 预设设置按栏目排列 AI 响应参数。角色和用户设定使用独立的列表行。页面底部的「完整设置」可进入对应板块的完整控件。
- 角色卡选择页支持搜索、排序、创建和导入。点角色卡会直接进入该角色当前的聊天。编辑角色卡仍可通过「完整设置」进入。
- 角色卡选择页与设置之间会翻转唱片盒，在盒体转到侧面时切换正背面。系统或酒馆启用简化动效时，两个页面直接切换。
- 拖动光盘盒露出的边缘或「旋转光盘盒」按钮可以旋转。标题、列表和底部按钮随盒体一起倾斜，仍可滚动和操作。旋转按钮也支持方向键与双击复位。系统或酒馆启用简化动效时，盒体保持静止。
- 手机通过 HTTPS 打开酒馆时可倾斜设备旋转唱片盒。看到「启用体感」时先点按并允许浏览器访问方向传感器。以常用的握持姿势点「校准体感」可以重新设置起点。
- 点击「返回」可离开设置。键盘焦点在面板或菜单中时也可按 Esc。标准手柄可以用方向键或肩键切换类别，B 返回。
- 加载完成后会尝试自动播放音乐。如果浏览器要求先交互，会在首次点击、触摸或按键时启动。音乐会在标题页、聊天和各设置页之间连续播放。阅读器顶栏可以播放、暂停、切歌，以及切换顺序、随机或单曲循环。「扩展程序 → 音乐与音效 → 管理曲目」可导入本地音频、选择或移除曲目。导入的文件保存在当前浏览器访问该酒馆地址时使用的 IndexedDB。

## 素材

标题字标、唱片盒封面和背壳、贴纸、底部标签和字体均从原版资源转换。硬件加速时，WebGL 在盒面附近的画布内绘制原版网格，并用背壳法线图和划痕遮罩计算暖色反光。软件渲染或 WebGL 不可用时，扩展改用 CSS 贴图和近似反光。各设置分类共用盒面投影。

歌词内页使用单独制作的透明盒壳、双页与单页纸面、唱片和电台贴花。盒壳以九宫格贴图保留边角比例。装饰和翻页动效共用正文区的实时边界，纸纹与可调底色分层。阅读素材随扩展和全局脚本一起打包。

白光明朝、侵食明朝、香萃积雪宋、秋叶圆体 16 和人偶仿宋 16 随包提供，许可与版权声明在字体目录和全局脚本中。缺字由默认宋体补齐。 [白光明朝](https://booth.pm/ja/items/8292561) · [侵食明朝](https://booth.pm/ja/items/8571086) · [香萃积雪宋](https://github.com/Miiiller/Xiangcui-Jixuesong) · [秋叶圆体 16](https://github.com/yzdnn/QiuYeYuanTi-16) · [人偶仿宋 16](https://github.com/yzdnn/RenOuFangSong-16)

主题的音乐、环境声和操作音效位于 `assets/mixtape/audio/`。内置曲目按顺序为《Yesterday and Today》（Yes）、《ポルターガイスト》和《If》（Bread），默认从第一首开始。酒馆助手版将音频内嵌在全局脚本 JSON 中。
