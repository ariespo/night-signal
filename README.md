# 夜间电台 · Night Signal 1.6

SillyTavern 1.19.0 起可用的 Mixtape 界面扩展。标题菜单接入继续聊天、最近聊天、角色管理和设置。

## 安装

### 从 GitHub 安装扩展

1. 在 SillyTavern 的顶部打开「扩展程序」，点击「安装扩展程序」。
2. 粘贴 `https://github.com/ariespo/night-signal.git`，保持分支为空，点击「安装」或「只给我安装」。
3. 输入框旁的魔杖菜单里选择「夜间电台」。后续可在「管理扩展程序」里检查和安装更新。

GitHub 提供安装和更新。装好以后，页面、字体、图像和声音都由你正在使用的 SillyTavern 服务提供。

### 其他安装方式

**手动安装**。从 [GitHub Releases](https://github.com/ariespo/night-signal/releases) 下载并解压 `night-signal-1.6.0.zip`，将其中的 `night-signal` 文件夹放入 SillyTavern 的 `data/<用户名>/extensions/`。默认位置为 `data/default-user/extensions/night-signal/`。更新时覆盖同名文件并刷新酒馆。若曾手动安装且想改用 GitHub 更新，可先备份现有扩展目录并将它移到 `extensions/` 之外，再用上面的链接安装。

**酒馆助手版**。从 [GitHub Releases](https://github.com/ariespo/night-signal/releases) 下载「酒馆助手全局脚本（JSON）」，在「酒馆助手 → 脚本 → 全局脚本 → 导入」选择下载的文件，然后开启「夜间电台」。原生扩展和全局脚本任选一种。

**UI 主题预设**。在「用户设置 → UI 主题」导入 `Mixtape-夜间电台-主题.json` 可以应用聊天颜色与基础外观。标题菜单、转场、旋转与音频由扩展版或酒馆助手版加载。

## 操作

- 「设置」和酒馆顶部原有的图标都可以打开唱片盒细页。顶部分类可以切换九个主题页面，独立渲染的选项通过酒馆的事件读写实际设置。使用左右箭头切换枚举和开关，拖动有内嵌读数的进度条调整范围参数。
- 世界书可直接调激活参数和匹配规则，也可进入书库、条目列表、正文编辑和筛选。只滚动唱片盒中央的列表，标题、Hot Stuff 贴纸和底部两张标签固定在盒面。关键词和正文编辑由酒馆保存。
- AI 参数和格式化模板按栏目排列，背景、角色和用户设定使用独立的列表行。页面底部的「完整设置」可进入该板块的扩展控件，扩展条目也可打开其专用界面。
- 拖动光盘盒露出的边缘或「旋转光盘盒」按钮可以旋转。标题、列表和底部按钮随盒体一起倾斜，仍可滚动和操作。旋转按钮也支持方向键与双击复位。系统或酒馆启用简化动效时，盒体保持静止。
- 点击「返回」可离开设置。键盘焦点在面板或菜单中时也可按 Esc。标准手柄可以用方向键或肩键切换类别，B 返回。
- 浏览器允许播放后，标题与设置中的「声音」按钮可快速静音。「扩展程序 → 夜间电台 · 主题选项」可以调节音乐、环境声、过场、操作音效，或改变启动行为。

## 素材

标题字标、唱片盒封面和背壳、贴纸、底部标签和字体均从原版资源转换。硬件加速时，WebGL 在盒面附近的画布内绘制原版网格，并用背壳法线图和划痕遮罩计算暖色反光。软件渲染或 WebGL 不可用时，扩展改用 CSS 贴图和近似反光。九个设置分类共用盒面投影。

主题使用原版菜单的电脑环境声，以及原版唱针划碟、确认、滑动、换页和关闭音效。标题曲《Slater Synth Track》取自原版曲库，约 5 分 29 秒。标题进入设置时音乐淡出，菜单环境声继续播放。
